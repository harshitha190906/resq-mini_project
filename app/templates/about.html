About ResQNet

ResQNet studies how emergency communication networks behave when links are heavily congested, and evaluates routing algorithms that keep critical messages flowing reliably.

Planned Algorithms

  • Dijkstra shortest-path routing
  • Congestion-aware dynamic rerouting
  • Priority-based message queuing
  • Adaptive backoff & retry strategies

Tech Stack

  • Python Flask backend
  • Vanilla HTML / CSS / JavaScript
  • Chart.js for visualisation
  • Python standard library for algorithms
